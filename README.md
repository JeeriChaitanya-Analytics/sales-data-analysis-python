# Sales Data Analysis Project

## 📌 Overview
This project analyzes sales data using Python by building a modular data pipeline.

## ⚙️ Tech Stack
- Python
- Pandas

## 🏗️ Project Structure
- extract.py → Loads data
- transform.py → Cleans and transforms data
- analysis.py → Generates insights
- main.py → Runs the pipeline

## 📊 Key Insights
- Identified top customers by revenue
- Found highest revenue-generating products
- Analyzed city-wise sales performance
- Evaluated monthly revenue trends

## ▶️ How to Run
```bash
python main.py
